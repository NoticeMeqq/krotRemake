## Что изменилось с v0.3.0

- **Обновление KrotRemake из окна «Версии».** В окне видны установленная версия и последний релиз. Кнопка **«Проверить обновления»** запрашивает сведения о выпуске на GitHub по требованию, даже если файл узлов ещё не открыт.
- **Установка новой версии.** Кнопка **«Обновить»** скачивает сборку, сверяет её с `SHA256SUMS` и перезапускает приложение. Если обновление на месте недоступно, кнопка **«Скачать»** открывает страницу релиза.
- **Проверки интерфейса.** Добавлены тесты ручной проверки, обновления, повторной попытки после ошибки и перехода к загрузке.

Контрольные суммы сборок для Windows, macOS и Linux опубликованы в файле `SHA256SUMS`.
