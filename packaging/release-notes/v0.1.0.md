Крот помогает развернуть VPN на своих серверах. Можно настроить двухсерверный каскад или один сервер. Мастер проверяет подключение, устанавливает выбранные модули с автоматическим откатом и выдаёт ссылки и QR-коды для устройств.

## Что нового

- **Подключения для устройств.** Крот создаёт подписку и профиль AmneziaVPN за один шаг. В подписку для INCY на iOS и Android сразу входит AmneziaWG, а также доступные входы VLESS XHTTP, VLESS PQ и Hysteria2. В карточке есть отдельная ссылка для AmneziaVPN.
- **Каскад.** При недоступности IPv4 туннель может переключиться на IPv6, если между серверами есть IPv6-связность.
- **Управление серверами.** Серверы каскада собраны в одной карточке. Для каждого доступны свои настройки, а в окне статистики отображаются трафик и время работы и есть кнопки перезапуска.
- **Telegram-бот.** Дашборд показывает трафик по протоколам и состояние серверов и входов.
- **Сайт на узле.** Из приложения можно опубликовать статический сайт целиком, включая HTML, CSS, JavaScript и другие файлы проекта.

## Первый запуск

- **Windows.** Для приложения с окном нужен Microsoft Edge WebView2. Сборки не подписаны.
- **macOS.** Распакуйте архив и перенесите приложение в папку «Программы». Сборка не подписана.
- **Linux.** Установите GTK 3 и WebKitGTK 4.1. Инструкции и скрипт `install.sh` находятся в архиве приложения.

Для создания единой подписки на существующей установке обновите модуль `subscriptions` на входном узле.
