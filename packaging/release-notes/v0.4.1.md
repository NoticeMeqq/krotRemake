## Что изменилось с v0.3.1

- **Параметры подписки.** Кнопка «Параметры» рядом с устройством открывает окно для настройки MTU, DNS и интервала Persistent Keepalive для AmneziaWG. Изменения появляются в единой подписке INCY и в файле AmneziaVPN. Адрес подписки и ключи устройства сохраняются.
- **Мастер-профиль.** Кнопка в разделе «Клиенты» задаёт параметры AmneziaWG по умолчанию для новых подписок на выбранном узле. Каждая подписка копирует значения при создании и может менять их отдельно.
- **Проверки.** Добавлены тесты окна настроек и публикации совместимых профилей для INCY и AmneziaVPN.

Чтобы открыть настройки на уже настроенном узле, обновите настольное приложение и модуль «Подписки» на этом узле. После изменения параметров обновите подписку в INCY и переподключитесь.

Сборки для Windows, macOS и Linux сопровождает файл контрольных сумм `SHA256SUMS`.
