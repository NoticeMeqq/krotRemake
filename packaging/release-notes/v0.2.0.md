## Что изменилось с v0.1.0

- **Резервное копирование по запросу.** Кнопка **«Создать копию сейчас»** запускает службу резервного копирования на выбранном сервере, скачивает новый зашифрованный архив и проверяет SHA-256 и содержимое. **«Забрать свежую копию»** скачивает последнюю готовую копию.
- **Перезагрузка сервера из Telegram.** В меню бота появился раздел **«Сервер»** (`/servers`). Администратор в личном чате может перезагрузить узел, на котором работает бот. Подтверждение одноразовое и действует 60 секунд. Если идёт установка, обновление или откат модуля, бот отклоняет запрос.
- **AmneziaWG в INCY Desktop.** Уточнены подписи и документация. В INCY Desktop 3.9.1 на Windows проверен импорт AmneziaWG из единой подписки Крота. Если в INCY сохранена ссылка совместимости, замените её ссылкой из **«Копировать ссылку»** в карточке подключения.
- **Проверки настольного приложения.** GitHub Actions собирает интерфейс и запускает тесты Go и Playwright. Проверяются переключение серверов, статистика и перезагрузка, резервные копии, подписки, публикация сайта, обновления, мастер установки и оповещения.
- **Документация.** README описывает возможности форка и содержит ссылку на [оригинальный Крот](https://github.com/xDarkOne/krot) и его авторов.

## Как обновиться

Скачайте приложение или CLI для своей системы и архитектуры. В релиз входят сборки для Windows x64 и ARM64, macOS Intel и Apple Silicon, Linux x64 и ARM64. Контрольные суммы опубликованы в файле `SHA256SUMS`. [Руководство пользователя](https://github.com/REPO/blob/v0.2.0/docs/USAGE.md)

Чтобы открыть панель перезагрузки на уже настроенном сервере, обновите модуль `vpn-bot`. Для резервного копирования по запросу используется установленный модуль `backup`.
